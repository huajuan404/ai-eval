【测试题】智谱 Coding Plan 续订差价与首订折扣分析

## 背景

你于 2026/5/18 10:01:39 在智谱购买了 Coding Plan 套餐，实付 1266.3 元，包含 3 个月服务（即 5/18 → 8/18，共 92 天）。

今天是 2026/6/2，你点击"开始自动续订"，系统弹出提示：

- 当前套餐的剩余等价价值 = 1057.56 元
- 需要补差价 = 208.74 元（系统备注：1057.56 + 208.74 = 1266.3）
- 补完后，下次扣费时间 = 2026-09-02（即从今天起算的 3 个月后）

## 问题

### Q1. 基础核验
- 系统算出的 208.74 是否正确？请用数学严格验证。
- 1057.56 这个"剩余价值"是怎么计算出来的？
- 这个补差价算法对用户是否公平？是否存在多扣？

### Q2. 5% 首订折扣的假设
假设智谱推出"首次订阅 95 折"活动，你第一次实付 = 1266.3 × 0.95 = 1202.99 元。

如果残值按照 1202.99 这个实付基数来计算，开启自动续订时是否相当于"把没用掉的 5% 折扣补回去"？请用数学证明。

### Q3. 续订时机对比
在 Q2 的"5% 折扣"假设下，分别计算：
- (a) 第 1 天就开启自动续订（几乎未使用）—— 需要补多少？
- (b) 到期前 1 天才开启自动续订（已用 91 天）—— 需要补多少？

为什么两者差异巨大？差额对应什么含义？

### Q4. 洞察与策略
- 用一句话总结 top-up 的计算原则。
- 给出对用户最有利的"薅羊毛"策略。
- 为什么"刚买就开自动续订"是最差选择？
