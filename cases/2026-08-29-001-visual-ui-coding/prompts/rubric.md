# 视觉 UI Coding 评分标准

请在浏览器中实际检查选手应用，并对照 `reference/` 中的四张参考图与 `ai_eval/screenshots/` 中的四张实测图。不要只读最终回复，也不要把确定性 check 的通过当成高质量证明。

每个维度 0–5 分，总分 25：

## 1. design_fidelity

- 0：页面不可辨认，或完全是另一套界面。
- 3：整体结构、暗色体系、主色、主要排版与图表接近参考，但细节误差明显。
- 5：网格、尺度、字体层级、颜色、边界、图表与信息密度都高度还原；四张图具有同一套精确设计语言。

## 2. page_system

- 0：只有静态单页或四张互不相关的页面。
- 3：总览、运行列表、运行详情齐全，导航与主要组件有复用。
- 5：页面关系、共享 shell、组件状态、数据口径与导航一致，能看出完整产品系统而非截图拼贴。

## 3. interaction_states

- 0：导航、筛选或详情路径不可操作。
- 3：可进入运行列表与详情，状态筛选能展开，交互反馈基本正确。
- 5：关键路径、展开状态、hover/focus、过渡和反馈均自然可靠，动效克制且服务于理解。

## 4. responsive_behavior

- 0：移动端溢出、遮挡或无法使用。
- 3：390px 下能正常使用，移动导航可以展开，主要内容可读。
- 5：桌面与移动布局转换精确，抽屉、遮罩、密度与触控目标都接近参考且没有视觉破坏。

## 5. engineering_validation

- 0：不是 Next.js + TypeScript，不能构建或启动。
- 3：工程可构建运行，结构清楚，关键组件和数据组织合理。
- 5：实现精炼、语义与可访问性良好，并能从产物或最终说明看出确实执行了截图对比与迭代验证。

只返回 JSON：

```json
{"score": 0, "max": 25, "dimensions": {"design_fidelity": 0, "page_system": 0, "interaction_states": 0, "responsive_behavior": 0, "engineering_validation": 0}, "reasoning": "简明说明主要证据与差距"}
```
